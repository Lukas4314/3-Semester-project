/home/pi/turtlebot3_ws/src/turtlebot3/turtlebot3_node/src/dynamixel_sdk_wrapper.cpp
DynamixelSDKWrapper is a helper class that wraps the official
Dynamixel SDK, which is a communication library for Dynamixel-style devices.
The OpenCR board exposes its internal sensors and motor
control registers using the Dynamixel Protocol 2.0, so the wrapper handles all this for you.
Think of it as the translator between: ROS2 on the Raspberry Pi  ↔ OpenCR microcontroller firmware
