\section{Conclusion}
In conclusion, a functional voice-controlled robot was developed, and was somewhat capable of localising sound sources using GCC-PHAT. MQTT worked sufficiently for real-time data transfer of audio data, despite not being designed for that purpose. However, the ESP32, did not have the computational power to use MQTT, and the microphone data was therefore sent using SPI to the Raspberry Pi. The sound localisation system achieved an angle error of approximately 16 degrees under optimal conditions. To further improve results, a higher sample rate and better quality microphones could be used, but would require higher data transfer rates and potentially more advanced hardware. 

The voice command interface worked well in quiet environments, but struggled with sound location in noisy environments, the ``stop'' command also had problems when the robot was moving due to motor noise. The calculated distance between the robot and the speaking human, when using the "come here" command was unrealiable, as this triangulation required high precision TDOA estimates, which could not be produced, a distance therefore had to be said to the robot as well as ``come here.'' Implementing noise reduction techniques and a more flexible command identification system using an LLM could enhance performance in noisy settings. Overall, while the project demonstrated the feasibility of a voice-controlled robot with sound localisation capabilities, there are several areas for improvement to enhance accuracy and reliability.
