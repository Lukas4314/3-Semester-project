\subsection{GCC-PHAT}
GCC-PHAT (General-Cross-Correlation Phase Transform) is an algorithm that caulculates the TDOA (Time Delay Of Arrival) of a signal in relation to a reference signal. This is used to calculate where the signal is coming from by finding the phase shift between 2 different microphones spaced by a known distance and multiply the phase shift with the speed of sound.

In order to calculate the TDOA of a signal, the signal must be converted to frequency domain which is done by using FFT (Fast Fourier Transform). Then the signal can be compared to a reference signal by multiplying the signal with the complex conjugate of the reference signal. This is because multiplying a signal with the the complex conjugate of another signal gives the phase difference between the two signals, as represented by the difference in the imaginary part. The phase difference can then be used to calculate the TDOA by first applying an IFFT (Inverse Fast Fourier Transform) to convert the signal back to time domain. Next the difference is divided by the sample rate and then multiplied by the speed of sound (343 m/s) to get the TDOA. This process is done 3 times, because there are 3 microphones and therefore 3 different ways of comparing signals (microphone pair: 0 and 1, 0 and 2 and 1 and 2). 

Depending on what GCC-PHAT is used for a weighting can also be applied depending. In this project however, a weight of 1 (no weight, except for $\epsilon = 1 \cdot 10^{-8}$ is added to avoid division by 0) is applied. This is because the human voice has the full range of frequencies that the microphones can pick up.

The standard cross correlation is called xcorr, which only compares the magnitude of the signals which can vary a lot depending on the environment. GCC-PHAT in turn compares the phase difference between the signals by normalizing the amplitudes for all frequencies. This makes GCC-PHAT more robust to noise since the phase difference is more consistent across all frequencies in the signal compared to the magnitude. For this reason GCC-PHAT is used for sound localisation in this project.

\subsection{Triangulation}
By knowing the distance between the three microphones and the TDOA between each pair, the AOA (Angle Of Arrival) can be calculated. In practice a 3D grid is designed with a space of 10 cm between each point. For each point in the grid the expected TDOA for all three microphone pairs is calculated and compared to the measured TDOA. Then the point with the best fit is chosen as the calculated position of the sound source.
